02

Manejo y conversión de fechas

10 pts

Convertir una fecha en formato dd-mm-yyyy a la estructura Fecha, y mostrarla en el reporte en formato yyyy/mm/dd.

convertirFecha() usa sscanf con el patrón "%d-%d-%d" para separar día, mes y año directo del char* que llega del archivo — no hace falta tokenizar a mano porque sscanf ya sabe leer números separados por guiones. mostrarFecha() hace lo inverso: imprime con setw(2) / setw(4) y setfill('0') para que un día como el 5 salga como 05 y no se rompa el formato yyyy/mm/dd.

Fecha convertirFecha(char fecha[])
{
    Fecha f;
    sscanf(fecha, "%d-%d-%d", &f.dia, &f.mes, &f.anio);
    return f;
}

void mostrarFecha(Fecha f)
{
    cout << setfill('0') << setw(4) << f.anio << "/"
         << setw(2) << f.mes << "/"
         << setw(2) << f.dia
         << setfill(' ');
}

03–06

agregarCliente() · agregarEnvio() · agregarPaquete() · agregarSeguimiento()

40 pts

Cada función debe: aumentar el arreglo dinámico, conservar lo existente, agregar el nuevo elemento, actualizar el contador y liberar el arreglo anterior — usando new[] / delete[], sin vector/list/map.

Las cuatro funciones son el mismo patrón repetido a cada nivel de la jerarquía, así que basta mostrar una — agregarPaquete() — y el resto (Cliente, Envío, Seguimiento) son idénticas cambiando el tipo. El orden importa: primero se reserva el arreglo nuevo de tamaño n+1, se copian los n elementos viejos, se agrega el elemento nuevo en la última posición, y solo después de tener todo copiado se libera el arreglo anterior con delete[] — si se liberara antes, se perdería la información que aún no se había copiado.

void agregarPaquete(Envio &e, Paquete p)
{
    Paquete *nuevo = new Paquete[e.cantPaquetes + 1];
    for (int i = 0; i < e.cantPaquetes; i++)
        nuevo[i] = e.paquetes[i];
    nuevo[e.cantPaquetes] = p;

    delete[] e.paquetes;
    e.paquetes = nuevo;
    e.cantPaquetes++;
}

envios.cpp — agregarPaquete() (mismo patrón en las otras tres)

Un detalle que vale explicar porque no es obvio: al copiar nuevo[i] = e.paquetes[i], la copia del struct Paquete es superficial — copia el puntero seguimientos, no la memoria que apunta. Eso es intencional: la memoria de los seguimientos ya reservada sigue siendo válida y sigue siendo la misma, solo cambia el arreglo de Paquetes que la contiene. No hay fuga ni doble liberación porque el delete[] e.paquetes libera el arreglo de structs viejo, no la memoria de los seguimientos que cada struct apunta.

15 pts

Leer el archivo línea por línea, identificar el tipo de registro por el primer carácter (E/C/N/P/S) y construir la jerarquía completa usando las funciones agregarX(), sin variables globales.

cargarArchivo() mantiene tres punteros locales — clienteActual, envioActual, paqueteActual — que van apuntando al último elemento agregado en cada nivel. Como el archivo está ordenado jerárquicamente (un cliente aparece antes que sus envíos, un envío antes que sus paquetes, etc.), cada vez que llega una línea P o S ya se sabe a qué padre engancharla: al último que se agregó. splitCampos() separa la línea por comas con strtok, y el primer campo resultante (campos[0]) es justamente el identificador E/C/N/P/S.

Un punto fino: después de cada agregarX() hay que reapuntar el puntero "actual" a la nueva posición en el arreglo, porque agregarX() reserva un arreglo nuevo y libera el viejo — cualquier puntero que siguiera apuntando al arreglo anterior quedaría colgando. Por eso paqueteActual = &envioActual->paquetes[...] se recalcula cada vez, nunca se reutiliza el puntero de la iteración anterior.

08–10

calcularEnvio() · calcularCliente() · calcularEmpresa()

15 pts

Costo base + $5.000 por cada paquete delicado del envío. calcularCliente() debe usar calcularEnvio(), y calcularEmpresa() debe usar calcularCliente().

Las tres son una cadena de responsabilidad hacia arriba: calcularEnvio() es la única que mira los paquetes uno por uno y cuenta cuántos son 'D'; calcularCliente() no vuelve a tocar paquetes, solo suma lo que le devuelve calcularEnvio() por cada envío; y calcularEmpresa() hace lo mismo un nivel más arriba. Así cada función solo conoce el nivel inmediatamente debajo de ella.

float calcularEnvio(Envio e)
{
    int delicados = 0;
    for (int i = 0; i < e.cantPaquetes; i++)
        if (e.paquetes[i].tipoPaquete == 'D')
            delicados++;
    return e.costo + delicados * COSTO_DELICADO;
}

float calcularCliente(Cliente c)
{
    float total = 0;
    for (int i = 0; i < c.cantEnvios; i++)
        total += calcularEnvio(c.envios[i]);
    return total;
}

12

Liberación de memoria

5 pts

Liberar toda la memoria dinámica del nivel más profundo hacia el nivel superior, sin dejar nada sin liberar al terminar el programa.

liberarMemoria() baja primero hasta el fondo de cada rama (seguimientos de cada paquete) antes de liberar el nivel que los contiene, porque si se liberara un arreglo de Paquetes sin antes liberar los seguimientos de cada uno, esos punteros internos quedarían inalcanzables — fuga de memoria. El orden es exactamente el inverso al de construcción.

void liberarMemoria(Empresa &e)
{
    for (int i = 0; i < e.cantClientes; i++)
    {
        Cliente &c = e.clientes[i];
        for (int j = 0; j < c.cantEnvios; j++)
        {
            Envio &ev = c.envios[j];
            for (int k = 0; k < ev.cantPaquetes; k++)
                delete[] ev.paquetes[k].seguimientos;
            delete[] ev.paquetes;
        }
        delete[] c.envios;
    }
    delete[] e.clientes;
}
